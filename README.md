## 🚀 Featured Projects

### 🔹 [Semantic Embedding Explorer](https://github.com/TANMAYGUPTA28/semantic-embedding-explorer)
An interactive vector space projection platform rendering 512-dimensional embeddings via client-side t-SNE & UMAP with real-time D3.js manifold physics and Web Audio feedback.
- **Tech Stack**: React 18 · D3.js v7 · Web Audio API · Barnes-Hut t-SNE · Vite · Vanilla CSS
- **Key Features**: Live Top-K Nearest Neighbor laser tracking · Dynamic Perplexity & UMAP tuning · Cosine similarity confidence ranking · Responsive 60 FPS Canvas/SVG rendering · Audio telemetry
- 🔗 **Live Demo**: [tanmaygupta28.github.io/semantic-embedding-explorer](https://tanmaygupta28.github.io/semantic-embedding-explorer/)
- 🔗 **GitHub**: [github.com/TANMAYGUPTA28/semantic-embedding-explorer](https://github.com/TANMAYGUPTA28/semantic-embedding-explorer)

### 🔹 [MERN Full-Stack Analytics & Management Platform](https://github.com/TANMAYGUPTA28)
End-to-end full-stack web application featuring robust user authentication, dynamic data dashboards, and RESTful CRUD APIs backed by MongoDB.
